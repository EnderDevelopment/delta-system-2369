# Delta System

Enhance your FiveM experience with Delta System, featuring fly mode and auto pickup.

## Features

- **Fly Mode**: Toggle fly mode to move freely in the game world.
- **Auto Pickup**: Automatically pick up items within a specified radius.

## Requirements

- FiveM server with ESX framework installed.
- MySQL database for storing player settings.

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start delta_system` to your server.cfg file.
4. Import the database.sql file into your MySQL database.

## Usage

1. Connect to your FiveM server.
2. Approach the box in the game world.
3. Press the interaction key (default: E) to open the Delta System menu.
4. Use the menu to toggle fly mode and auto pickup.

## Configuration

- **FlySpeed**: Adjust the speed of fly mode in the config.lua file.
- **AutoPickupRadius**: Set the radius for auto pickup in the config.lua file.
- **BoxPosition**: Define the position of the box in the game world.
- **BoxColor**: Customize the color of the box.
